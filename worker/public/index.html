Get started

Install Vpay in minutes.

Download the zip, extract it, and load the folder into Chrome. No store review is required for this unpacked build.

Download extension ↓
  1. Download the extension.
    Save vpay-extension.zip to your computer.
  2. Extract the archive.
    Keep the extracted folder somewhere permanent.
  3. Open Chrome extensions.
    Visit chrome://extensions and enable Developer mode.
  4. Load unpacked.
    Choose the extracted Vpay folder, then pin Vpay from the puzzle menu.
  5. Create your account.
    Open the side panel and choose Create account.
